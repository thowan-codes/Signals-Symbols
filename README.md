# Signals & Symbols
An accessibility mod for **Voices of the Void**.

Signals & Symbols adds text labels to signal entries so their level can be identified without relying only on UI color.

## What it does
Adds an 'L0'-'L3' indicator to signals shown in:

- The signal list under the computer's Database tab
- The signal list in the Playback Panel of the Workstations

The original UI colors remain unchanged; the label is an additional visual cue.

## Signal-Level key
| Label | Original color |
| --- | --- |
| L0 | White |
| L1 | Red |
| L2 | Yellow |
| L3 | Green |

## Notes
This mod is visual-only. It does not change signal data, signal behavior, or progression.
